The issue asks for "`VersionConflictError` either way", but `save(..., expected_version=0)` raises `ResourceExistsError` on a taken id. So a caller who writes the handler the issue proposes, `except VersionConflictError:`, will not catch a lost create race. The draft close comment says "A lost race raises `ConflictError` in both cases", which is accurate but easy to misread. Add this to the "differs from the issue's proposal on purpose" paragraph as a second intentional difference, and change the close comment to say it outright, for example: "`expected_version=0` raises `ResourceExistsError` and `>0` raises `VersionConflictError`.
